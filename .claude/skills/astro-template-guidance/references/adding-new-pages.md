# Adding a page, route or section

## A new static page

Create a file under `src/pages/`. The filename is the route: `src/pages/pricing.astro`
serves `/pricing`.

```astro
---
import BaseLayout from '../layouts/BaseLayout.astro';
---

<BaseLayout
  wfPageId="6a84225ef14a6cfa777048b7"
  title="Pricing || Consulting Website Astro Theme"
  description="Simple, transparent consulting packages."
  hidden="[to-top-0], [to-top-2], [to-top-4], .heading-style-2"
>
  <main class="main-wrapper">
    <!-- sections go here -->
  </main>
</BaseLayout>
```

### BaseLayout props

| Prop          | Required | Purpose                                                        |
| ------------- | -------- | -------------------------------------------------------------- |
| `wfPageId`    | yes      | Stamped on `<html>` and the footer form; copy one from a sibling page |
| `title`       | no       | Falls back to `site.json` `title`                              |
| `description` | no       | Falls back to `site.json` `description`                        |
| `ogImage`     | no       | Falls back to `site.json` `ogImage`                            |
| `ogType`      | no       | `website` (default) or `article` on detail pages               |
| `hidden`      | no       | Comma-separated selectors pre-hidden until IX2 animates them in |
| `wrapper`     | no       | `page-wrapper` (default) or `utility-page-wrapper`             |
| `jsonLd`      | no       | An object serialised into a `application/ld+json` script        |

**`hidden` matters.** Anything the page animates in from opacity 0 must be listed,
or it flashes in its final position before `webflow.js` boots. Copy the selectors
for the sections you reuse from the page you took them from.

## Add the page to navigation

Routes are not discovered automatically. Add an entry to `src/config/menu.json` —
see [page-configuration.md](./page-configuration.md). The current-page highlight
(`w--current`) is applied automatically by `src/lib/nav.ts` on exact path match.

## A new collection route

Dynamic routes need `getStaticPaths`. Follow the shape used by
`src/pages/services/[slug].astro`:

```astro
---
import BaseLayout from '../../layouts/BaseLayout.astro';
import { getServices, related, type Service } from '../../lib/content';

export async function getStaticPaths() {
  const services = await getServices();
  return services.map((service) => ({
    params: { slug: service.slug },
    props: { service, relatedServices: related(services, service.slug, 3) },
  }));
}

interface Props { service: Service; relatedServices: Service[] }
const { service, relatedServices } = Astro.props;
---
```

Never call `getServices()` in both `getStaticPaths` and the component body — pass
the data through `props` so it is fetched once per build.

## A new section inside a page

Copy a `<section>` from `/style-guide` or from any existing page. Sections are
self-contained: the outer `section_*` class plus a `section-gap` and
`container-main w-container` wrapper.

If the section repeats a collection, wrap the `w-dyn-item` element in a `.map()`
and keep the `w-dyn-list` / `w-dyn-items` / `w-dyn-item` classes — see
[content-management.md](./content-management.md).

## Reserved routes

`src/pages/404.astro` becomes `dist/404.html`; most hosts serve it automatically
for unmatched paths. `sitemap-index.xml` and `sitemap-0.xml` are generated by
`@astrojs/sitemap` — do not add files with those names.
